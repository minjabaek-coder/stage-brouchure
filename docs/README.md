## 문서 작성·갱신 규칙

- **SSOT 우선**: `00-prd.md` 가 모든 결정의 기준. 충돌 시 PRD 가 이긴다
- **변경 흐름**: PRD 갱신 → README/01–06 일괄 동기화
- 언어: **한국어**. 기술 용어는 영문 병기 가능 (예: 라우팅 (routing))
- 식별자: `FR-G##` (관객용 기능), `FR-A##` (관리자용 기능), `ENT-##` (엔터티), `SCR-##` (화면)
- 우선순위: **P0** (MVP 필수) / **P1** (런칭 후) — PRD v1.1 의 모든 기능은 P0
- 변경 이력은 git commit 메시지로 관리 (별도 changelog 파일 유지하지 않음)
